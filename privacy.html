Privacy policy

SocialUploader is a private tool that runs on its owner's own computer. This page explains what it does with Google account data.

What it accesses

When a YouTube channel is signed in, SocialUploader asks Google for permission to upload videos and manage that channel's videos and comments (the youtube.upload and youtube.force-ssl scopes). It uses this only to upload videos, set their thumbnails and details, read the channel's name and picture so the channel can be shown in the app, and post a comment on its own uploads.

How it is stored

The sign-in tokens Google returns are saved only on the computer running SocialUploader. They are not sent to any server other than Google's own APIs.

Sharing

SocialUploader does not sell, share, transfer or disclose Google user data to anyone, does not use it for advertising, and does not use it to train AI or machine-learning models. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google account's third-party access page.

Contact

Questions can be raised as an issue on this site's repository.
